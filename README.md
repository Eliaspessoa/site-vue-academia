# 🏋️‍♂️ FitSystem - Site para Academia (Vue.js)

Este é um projeto front-end de uma página web moderna e responsiva desenvolvida para uma academia, construída utilizando **Vue.js**. O objetivo é apresentar os serviços, planos de assinatura, horários de aulas e uma interface atrativa para novos alunos.

## 🚀 Tecnologias Utilizadas

* **[Vue.js 3](https://vuejs.org/)** (Composition API)
* **[Vite](https://vitejs.dev/)** (Empacotador e servidor de desenvolvimento rápido)
* **HTML5 / CSS3 / JavaScript (ES6+)**
* **Responsividade** (Mobile-first design)

## ✨ Funcionalidades

* 🏠 **Página Inicial (Home):** Seção de destaque (*Hero*) com chamada para ação (*CTA*).
* 💪 **Planos e Preços:** Tabela de valores e benefícios para os diferentes tipos de matrícula.
* 📅 **Grade de Horários:** Visualização rápida das modalidades disponíveis (Musculação, CrossFit, Dança, etc.).
* 📱 **Design Responsivo:** Adaptado perfeitamente para telemóveis, tablets e computadores.
